# Support

- Bugs: open a bug-report issue with revision, sanitized configuration and reproduction.
- Ideas: open a feature-request issue and explain the use case.
- Usage: use the question issue template after reading the quickstart and operations guide.
- Security: follow [SECURITY.md](SECURITY.md), not public bug reports.

This is a community-maintained starter with no paid support or response SLA.
Please avoid uploading private object content or credentials.
