## Unreleased — 0.1.0a1 developer preview

### Added

- Single-process FastAPI sidecar with authenticated REST and official MCP SDK tools.
- SQLite WAL job queue, startup recovery and incremental object manifest.
- Demo and read-only S3 storage adapters; text/Markdown and optional Docling parsing.
- Embedded LanceDB BM25, vector and hybrid search with cited chunks.
- FastEmbed adapter and explicitly lexical hash fixtures for offline demos/tests.
- React console, container recipes, contribution docs, CI and MinIO integration harness.

No stable V0.1 release has been published. Distributed operation is a roadmap item.
